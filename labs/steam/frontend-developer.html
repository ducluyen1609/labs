Frontend Developer

Sau khóa học, học sinh làm được gì? Thiết kế giao diện bằng Figma; xây dựng website responsive với HTML, CSS, JavaScript; kết nối API và phát triển, kiểm thử, triển khai ứng dụng Angular.

  1. 01Figma và tư duy UI/UX

    Học layout, typography, màu sắc, component và thiết kế nhiều thiết bị.

    Sản phẩm: Bộ thiết kế UI website, mẫu form, danh sách sản phẩm và tài liệu trình bày dự án.

  2. 02HTML, CSS và web responsive

    Học cấu trúc HTML, Box Model, Flexbox và cấu hình server ảo.

    Sản phẩm: Website giới thiệu tổ chức hiển thị tốt trên nhiều thiết bị và chạy trên server ảo.

  3. 03HTML5, CSS3, Grid và SEO

    Học dàn trang phức tạp, hiệu ứng, gỡ lỗi, SEO và tối ưu hiệu suất.

    Sản phẩm: Trang web tĩnh phức tạp, chuẩn SEO và tối ưu tốc độ.

  4. 04Giao diện với Bootstrap

    Học Grid System, Form, Modal, Carousel, media query và CSS tùy chỉnh.

    Sản phẩm: Website tin tức tương thích di động và máy tính.

  5. 05JavaScript cơ bản và DOM

    Học biến, vòng lặp, rẽ nhánh, sự kiện và thao tác DOM.

    Sản phẩm: Website tin tức có hiệu ứng và tương tác JavaScript.

  6. 06JavaScript ES6+ và bất đồng bộ

    Học Arrow Function, Destructuring, Promise, Async/Await và xử lý lỗi.

    Sản phẩm: Website có tương tác phức tạp và mã nguồn được tổ chức hiện đại.

  7. 07Kết nối API bên thứ ba

    Học Fetch API, JSON, AJAX, CORS và RESTful API.

    Sản phẩm: Ứng dụng web hiển thị dữ liệu động từ API thời tiết, tin tức hoặc nguồn khác.

  8. 08Angular nền tảng

    Học Component, Data Binding, Input/Output và Lifecycle Hooks.

    Sản phẩm: Ứng dụng Angular cơ bản hiển thị dữ liệu, xử lý sự kiện và quản lý trạng thái.

  9. 09Angular nâng cao

    Học Router, RxJS, NgRx, Reactive Forms, Dependency Injection và Unit Test.

    Sản phẩm: Ứng dụng Angular quy mô lớn, nhiều trang, gọi API và quản lý dữ liệu phức tạp.

  10. 10Bảo mật và triển khai Angular

    Học Angular Material, JWT/OAuth, SSR và triển khai Cloud/Firebase.

    Sản phẩm: Hệ thống web có xác thực người dùng được đưa lên Internet, kèm tài liệu và báo cáo kỹ thuật.
