Backend Developer

Sau khóa học, học sinh làm được gì? Viết chương trình và game Python, tạo ứng dụng giao diện, thiết kế cơ sở dữ liệu, xây dựng website Django có quản lý người dùng, thương mại điện tử và API có xác thực.

  1. 01Python nền tảng

    Học biến, kiểu dữ liệu, if/else, vòng lặp, danh sách, hàm và xử lý lỗi.

    Sản phẩm: Phần mềm quản lý học sinh cơ bản và ứng dụng nhỏ như game đoán số.

  2. 02Xử lý dữ liệu Python nâng cao

    Học List Comprehension, Map, Filter, Reduce, Lambda và dữ liệu đa chiều.

    Sản phẩm: Ứng dụng tổng hợp xử lý danh sách, chuỗi và báo cáo quy trình giải bài toán.

  3. 03Đồ họa và game với Turtle

    Học thuật toán hình học, sự kiện chuột/bàn phím và đồ họa 2D.

    Sản phẩm: Game 2D cuối khóa như Snake hoặc Chiến binh không gian.

  4. 04OOP và ứng dụng Tkinter

    Học lớp, đối tượng, kế thừa, giao diện và lập trình hướng sự kiện.

    Sản phẩm: Phần mềm giao diện hoàn chỉnh như máy tính bỏ túi hoặc ứng dụng vẽ.

  5. 05Phát triển game với PyGame

    Học Game Loop, FPS, hoạt ảnh, va chạm, trọng lực và độ khó lũy tiến.

    Sản phẩm: Game 2D hoàn chỉnh như Snake, xếp gạch, bóng nảy hoặc Flappy Bird.

  6. 06Cơ sở dữ liệu SQL và NoSQL

    Học mô hình ER, truy vấn, chuẩn hóa, Indexing, Backup/Restore với MySQL/PostgreSQL và MongoDB.

    Sản phẩm: Hệ thống cơ sở dữ liệu quan hệ và NoSQL cùng sơ đồ ER.

  7. 07Django cơ bản và website cá nhân

    Học Model, Template, URL, Bootstrap và triển khai web.

    Sản phẩm: Website thông tin cá nhân được đưa lên server, kèm tài liệu thiết kế.

  8. 08Django ORM, CMS và bảo mật

    Học ORM, Django Admin, HTTP/HTTPS, xử lý lỗi và phòng chống XSS, CSRF.

    Sản phẩm: Website có hệ thống quản lý nội dung và các chức năng bảo mật.

  9. 09Người dùng và tối ưu Django

    Học Forms, đăng ký/đăng nhập, phân quyền, file tĩnh, Caching và tối ưu truy vấn.

    Sản phẩm: Website quản lý người dùng với chức năng bình luận động.

  10. 10Website thương mại điện tử

    Học giỏ hàng, đơn hàng, Social Login và tích hợp API thanh toán.

    Sản phẩm: Website bán hàng có đặt hàng và chức năng thanh toán trực tuyến.

  11. 11REST API với Django REST Framework

    Học endpoint CRUD, Serializer, JWT, Pagination, Throttling và tài liệu API.

    Sản phẩm: Hệ thống API có xác thực cùng tài liệu Swagger hoặc Postman.
